다시는 낚시 안 해

작은도서관 지원사업 ‘성대골 초록 지구 수비대’에서 진행한 환경 그림책 연계 수업입니다. AI를 활용해 활동 아이디어와 수업 자료 구성을 구체화하고, PPT·색칠 도안·자석 낚시 체험으로 이어지는 독후활동을 만들었습니다.

그림책 연계환경교육PPT 제작체험 활동

기획 의도

구름 위에서 낚시를 하며 지구의 물건과 쓰레기, 동물들이 낚여 올라오는 이야기에서 출발했습니다. 환경오염 문제를 어린이의 눈높이에서 생각하고, 듣고 끝나는 수업이 아니라 직접 만들고 체험하는 활동으로 연결했습니다.

AI를 활용해 만든 과정

1. AI와 활동 아이디어 기획그림책의 이야기와 환경 주제를 어린이가 직접 참여하는 독후활동으로 연결했습니다.
2. 교육 자료 구성지구 온난화 내용을 어린이 눈높이에서 이해할 수 있도록 PPT 자료를 구성했습니다.
3. 활동 자료와 교구 제작색칠 도안을 출력하고 클립을 붙여 자석 낚시 체험에 사용할 수 있도록 준비했습니다.
4. 실제 수업으로 적용완성한 자료를 활용해 책 읽기, 환경 이야기, 직접 참여하는 놀이를 하나의 수업으로 진행했습니다.

그림책을 읽은 고학년 어린이가 탄소제로 실천 미션을 해결하는 웹 방탈출 활동입니다. AI를 활용해 아이디어와 미션 구성을 구체화하고, 실제로 작동하는 웹 체험 페이지로 구현했습니다.

환경교육AI 활용웹 개발인터랙티브 콘텐츠

프로젝트 개요

지구 온난화로 위기에 놓인 북극곰의 이야기를 출발점으로 삼아, 어린이들이 탄소제로 실천 방법을 미션 형태로 경험하도록 구성했습니다. 읽기 활동을 문제 해결과 참여형 체험으로 확장한 프로젝트입니다.

AI를 활용해 만든 과정

1. AI와 미션 아이디어 구상책의 주제를 탄소제로 실천 문제와 연결하고, 어린이가 해결할 미션을 구성했습니다.
2. 이야기와 진행 순서 만들기참여자가 순서대로 문제를 풀 수 있도록 방탈출의 흐름과 화면 구성을 정리했습니다.
3. 웹 페이지 제작HTML5, CSS3, JavaScript, jQuery, Bootstrap을 활용해 화면과 상호작용을 구현했습니다.
4. 교육 활동으로 활용고학년 어린이가 직접 미션을 풀며 환경 실천 방법을 생각하도록 만들었습니다.

사용 기술

교육 콘텐츠의 진행 흐름과 사용자의 상호작용을 웹으로 구현하기 위해 활용한 기술입니다.

HTML5CSS3JavaScriptjQueryBootstrap

직접 체험하기

실제 방탈출 페이지가 배포되면 이 버튼에 공개 주소를 연결합니다. 현재 미리보기에서는 연결 주소가 아직 제공되지 않아 테스트 링크 준비 상태로 표시합니다.
